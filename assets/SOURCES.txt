Original logo files are preserved and remain the source for project detail dialogs through scripts/content.js. The original Skills PNG has a white outer background; the detail dialog clips it to the existing official eCapture hexagon silhouette without changing its internal artwork or white lenses.

logos/homepage-3d/: homepage-only glossy 3D interpretations generated using built-in image_gen on 2026-11-22. Each uses its original project identity and the user-approved glossy eCapture concept (design/concepts/gojue-v4-3d-logos/ecapture-concept-glossy.png) as references. Yellow and ivory rounded forms, polished black resin details, white lenses and genuine alpha backgrounds match the computing-themed scene. Prompt archive: assets/logos/homepage-3d/prompts.txt. ecapture-body.png intentionally omits its eyes; index.html overlays eye.png twice inside the existing animated #bee-eyes SVG group. The other four files are ecapture-skills.png, ecaptureq.png, ecapture-decryptor.png and ebpfmanager.png. Original project artwork is not overwritten.

landscape.png: generated using built-in image_gen from the user-approved computing-themed concept (design/concepts/gojue-v3-computing/homepage.png). Prompt: assets/landscape-prompt.txt. Preserves the mist-blue and cream soft 3D style, with a terminal, processor, keycaps, Ethernet connector and subtle circuit traces around the edges. It contains only scenery; website text, logos and interactive connections are separate elements.

ebpfmanager.svg: newly designed for this website at the user's request. Editable vector artwork extending the existing logo family, not an existing upstream logo. Reuses the exact bee path groups from ecapture.svg in a yellow chip-shaped carrier with twelve probe terminals. Palette: #FFCC1A, #26282B, #FFFFFF. Transparent background. Preserved for project details; the homepage uses its glossy 3D interpretation.
ebpfmanager.png: transparent 512px preview rasterized directly from ebpfmanager.svg with librsvg. Project details use the SVG original.
